S&P500 수익률과 코스피200 수익률

질문: S&P500이 움직일 때 코스피200은 얼마나 같이 움직이는가?

  • 단순 회귀(한 개 설명변수)에서는 양의 연관관계가 자주 관찰됨.

S&P500 수익률과 코스피200 수익률: 다중 회귀 분석

  • 관심 대상: S&P500 수익률이 코스피200 수익률에 미치는 연관성.
  • 통제 필요: 시장 충격 크기 (abs_ret_sp500).

\[ \textrm{KOSPI200 return}_i = b_0 + b_1\,\textrm{S\&P500 return}_i + b_2\,|\textrm{S\&P500 return}_i| + e_i \]

다중 회귀 분석의 목적

  • 단순 선형 모형: \[ y_i = b_0 + b_1 x_i + e_i \]

  • 인과적 해석을 시도하려면, 다른 요인들을 일정하게 유지하는 조건이 필요.

  • 따라서 \(y_i\)와 \(x_i\) 모두와 관련된 변수를 함께 포함하는 다중회귀가 필요.

다중 회귀 분석 모델

확장된 회귀 모형:

\[ y_i = b_0 + b_1 x_{1,i} + b_2 x_{2,i} + \dots + b_k x_{k,i} + e_i \]

  • \(x_1, x_2, \dots, x_k\): 설명변수
  • \(b_1, b_2, \dots, b_k\): 각 설명변수의 회귀계수

추정(OLS)

\[ \sum_i e_i^2 = \sum_i (y_i - \hat{y}_i)^2 \]

다중 회귀 분석: 해석

  • 절편 \(b_0\): 모든 설명변수가 0일 때의 예측값
  • 기울기 \(b_k\): 다른 변수들이 고정될 때, \(x_k\)가 1단위 증가할 때 \(y\)의 평균 변화
  • 단순회귀와 달리 “다른 변수 고정” 해석이 가능

R을 사용한 다중 회귀 분석

lm(formula = dependent_variable ~ independent_1 + independent_2 + ...,
   data = data.frame)

\[ \text{KOSPI200 return}_i = \color{#d96502}{b_0} + \color{#d90502}{b_1}\text{S\&P500 return}_i + \color{#027D83}{b_2}\text{high\_vol}_i + e_i \]

완전 다중공선성(Perfect Collinearity)

  • 추가 변수는 새로운 정보를 제공해야 함
  • 한 설명변수가 다른 설명변수의 완전한 선형결합이면 안 됨

\[ x_2 \neq a x_1 + b \]

  • 완전 다중공선성: 회귀추정 불가 또는 자동 드롭
  • 관측치 수가 변수 수보다 충분히 커야 함

누락변수 편의 (Omitted Variable Bias, OVB)

  • 중요한 통제변수를 생략하면 관심 계수에 편향이 생김.

  1. 단순회귀: \[ y = b_0 + b_1 x + e \]

  2. 진짜 모형(누락변수 포함): \[ y = c_0 + c_1 x + \color{#d90502}{c_2} z + e \]

  3. 누락변수와 설명변수 관계: \[ z = d_0 + \color{#d96502}{d_1} x + e \]

누락변수 편의 (Omitted Variable Bias, OVB)

\[ \text{OVB} = \color{#d90502}{c_2} \times \color{#d96502}{d_1} \]

즉,

\[ b_1 = c_1 + OVB \]

  • \(z\)가 생략되면 \(b_1\)은 \(c_1\)에서 벗어남.

누락변수 편의 (Omitted Variable Bias, OVB)

\[ \text{OVB} = \underbrace{\text{생략변수의 효과}}_{\color{#d90502}{c_2}} \times \underbrace{\frac{Cov(x,z)}{Var(x)}}_{\color{#d96502}{d_1}} \]

  • 관측 가능한 경우 OVB 크기를 직접 계산 가능
  • 관측 불가능한 경우 부호(sign) 판단이 핵심

수정된 결정 계수 (Adjusted \(R^2\))

  • \(R^2\)는 변수를 추가하면 거의 항상 증가
  • 의미 없는 변수 추가까지 보상하는 한계가 있음
  • Adjusted \(R^2\)는 변수 수에 패널티를 부여
